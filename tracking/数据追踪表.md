## 三、双篇对照复盘问题（第 7 天回答）

1. 两篇哪篇阅读更高？是标题、选题，还是分享渠道导致的差异？
2. 第二篇比第一篇涨粉多还是少？（看"持续性"这个维度）
3. 文末互动问题各收到几条有效留言？哪个问题更能勾人？
4. 哪个渠道带来最多阅读？值不值得下一篇重点押注？
5. 下一篇（第 3 篇）要改进什么：标题 / 封面 / 开头 / 案例？

## 五、迭代闭环（v1 → v2 触发器）

```
发布 → 按表二记录数据 → 按表三复盘
   → 若：某标题点击明显高 / 某段被大量分享 / 评论区有明确新需求
   → 下一篇：标题沿用高点击公式，结构复用高分享段落，并回应评论区需求
```

**新号现实预期**：第一篇 100 阅读已不错。C7 看的是**趋势**（第二篇是否比第一篇好）和**群内影响**，不是和大号比绝对值。
