一个连 Git 都搞不明白的软件工程大一新生，想在自己笔记本上跑一个"能记住上次聊过啥"的 AI。这是我折腾一周、推翻三次、最后真的跑通的全过程。

先说结果，再说丢人

上周这个时候，我对着命令行里一行 Memory saved to memory.json 的输出，愣了三秒。

成了。

一个跑在我自己电脑上、不联网、不用花钱调 API 的小 Agent，真的记住了：我喜欢楷书、我在练兰亭序、我膝盖不好别推荐我蹲很久的练字帖。

你现在听到"本地大模型 Agent"可能觉得特别玄。我先说清楚我是谁：我，郑州西亚斯学院软件工程 2025 级，李亚轩，自评零基础。开学前我连"环境变量"是啥都要百度三遍。

但我愣是把它做出来了。这篇文章不吹不黑，把我踩的坑、走的弯路、以及三次推翻重来的过程，全写出来。

我为啥非要折腾"本地"？

起因很简单。我们 C4D 这个技能挑战，要求做一个"本地大模型 Agent"。一开始我是抗拒的：直接用网页版 AI 不就行了？

真动手才想明白三件事：

· 不花钱。网页版用多了要充额度，本地随便造。
· 数据不出本机。我把练字笔记、手写描述喂给它，不想传到别人服务器。
· 它是真的"我的"。关机再开它还在，这种感觉很不一样。

一句话：网页版是租房子，本地跑是自己装修。

第一晚：下载模型，就给了我下马威

我选的模型是 Gemma（Google 出的开源小模型，对配置友好）。敲下下载命令，然后……就开始等。进度条像蜗牛，我去食堂吃了顿饭，回来它还在爬。

等我兴冲冲加载起来问第一句话，它给我的回答是："对不起，我现在无法回答。"

我：？？？我下你两个多小时，你就给我看这个？

后来才知道，模型文件下了一半就断了，是个残血模型。我以为进度条走完就完事。

教训一：大文件下完一定校验一下，别信进度条。

重下，又是俩小时。这回能对话了，但慢得像挤牙膏。我一看任务管理器——内存占满，硬盘狂转。原来我让它加载了一个我这破笔记本根本扛不动的版本。

第二次翻车：它"记不住事"

模型能聊了，下一步是我真正想要的——让它有记忆。结果呢？每次关掉窗口再打开，它都像第一次见面："您好！请问有什么可以帮您？"

我：大哥，昨天才聊过。

这是我花最久才想明白的一个坑：大模型本身是没有记忆的。它每说一句话都是根据当前这段文字现编的，你一关窗口，它脑子里那点东西就全没了。

那"记忆"哪来的？答案特别朴素：是外面用文件存的。每次对话前，程序先去读一个 memory.json，把"主人喜欢楷书""膝盖不好"这些塞进提问前面；聊完再写回去。

模型还是那个没记性的模型，是外面这层"读写文件"的壳，让它看起来像有记忆。原来"记忆"就是一个读写 JSON 的小动作。

第三次换路：别硬刚

真正卡住我的，是"技能调用"。我想让它不只是聊天，还能调我写好的小工具。教程里让模型自己判断"什么时候该调工具"，我折腾半天，它就是不肯老实调，要么瞎编答案，要么调错参数。

最后我做了个重要决定：不硬刚了，换条对我友好的路子。我把流程改成"半自动"——如果用户话里带"笔顺"这种关键词，就直接调对应技能，模型只负责把话说自然点。

一开始我觉得"换路"是认怂，后来才明白：在自己能力不够时，选一条能跑通的笨办法，比硬撑一个高级架构重要一万倍。能跑，比优雅重要。

跑通的那一刻

凌晨一点多，加上 memory 读写、改成半自动调用，重跑一遍：

我："记住，我叫李亚轩，在练楷书。"
它："好的，已经帮你记下了。"

我关掉窗口，重新打开，问："帮我查个练字建议。"它没问我是谁，而是说："亚轩你好～你之前说在练楷书、膝盖不太好，那我推荐几个坐着就能练、不用久蹲的描红帖吧……"

我盯着屏幕真有点感动。它其实"啥也没记住"，只是每次都老老实实去读那个文件。但就这么个土办法，实现了我一开始想要的效果。

写给同样零基础的你

这一周我最大的收获，根本不是技术，是心态：

1️⃣ 别被名词吓住。拆开来就是：下个模型文件 + 读写一个 JSON + 几个关键词判断。
2️⃣ 能跑比优雅重要。先做丑的，再做好的。
3️⃣ 报错不是针对你。谁都遇到过，它只是在等你去查它。
4️⃣ AI 是搭档不是替身。方向我定，活一起干。

一个月前我连环境变量都怕，现在我有了一个跑在自己电脑里、记得住我名字的小 Agent。技术不是聪明人的专利，是敢往下敲命令的人的。

你呢？你最想让电脑里的 AI 记住你的什么？评论区告诉我——点赞最高的那个需求，我下期真的去试着做出来。
