# 文章二 · 封面图说明（供后续制图）

> 用途：给设计师 / 制图工具的构图与文字说明，不是成品图。

## 一句话定位
"东西躺在我电脑里" → "它挂到了全世界都能访问的地方"，一张图讲完这个转变。

## 构图建议（横版 2.35:1 或公众号封面 900×383）
- **主视觉**：左右对比构图。左边是一个乱糟糟的电脑桌面文件夹，里面几个文件灰扑扑地堆着；右边是一个干净的网页仓库界面，文件整整齐齐排列，右上角有一颗小星星。
- **连接元素**：从左边文件夹到右边网页，画一道青蓝色的光/箭头，象征"发布"这个动作。
- **配色**：左半边偏暗灰（本地、无人问津），右半边干净明亮（公开、被看见）；唯一强调色仍是青蓝色。
- **氛围**：平实、有手作感，不要做成大佬味的黑板 + 终端绿。

## 封面文字（两行，居中偏下）
- 主标题（大字）：**不会写代码，我也开源了**
- 副标题（小字）：零基础 · C4 做技能 → C5 发 GitHub 实战

## 不要出现
- 不要出现真实账号头像、真实仓库名（可用占位的 "my-skills"）。
- 不要堆真实报错截图（怕泄露本机路径）。
- 不要用火箭、冲上云霄这类俗套"成功学"素材。
