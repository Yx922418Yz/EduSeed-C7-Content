## 这个仓库是什么

把我在 C4D / C4→C5 的真实经历，写成两篇真诚、可发布的公众号复盘文章。每篇都给齐：Markdown 原稿 + 可直接粘贴的公众号内联排版 HTML + 10 个备选标题 + 封面图说明。

## 如何使用（发布一篇文章）

1. 打开 `articles/0X_xxx/公众号排版.html`，浏览器预览排版。
2. Ctrl+A 全选复制 → 按 `sop/公众号发布SOP.md` 第 3~8 步粘贴到公众号后台。
3. 按 `封面图说明.md` 做封面、按 `备选标题.md` 选标题。
4. 发布后，把链接回填到 `LiYaxuan_C7_文章链接.md`，把数据填进 `tracking/数据追踪表.md`。
