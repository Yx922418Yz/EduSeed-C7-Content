# 文章一 · 封面图说明（供后续制图）

> 用途：给设计师 / 制图工具（如稿定、Canva、即梦）的一句话与构图说明，不是成品图。

## 一句话定位
一个普通大学生的笔记本屏幕，从"死命令行"到"一个会记住主人的小 AI"的反差感。

## 构图建议（横版 2.35:1 或公众号封面 900×383）
- **主视觉**：一台打开的笔记本电脑，屏幕里不是冷冰冰的代码，而是一个温和的对话气泡，气泡里写着"亚轩你好，你在练楷书～"。
- **情绪锚点**：屏幕旁边飘出一张小小的便签纸，上面手写着"喜欢楷书 / 膝盖不好"——视觉化"记忆"这个抽象概念。
- **配色**：整体深色桌面氛围，屏幕光用青蓝色（马尔代夫蓝/马卡龙蓝绿）作为唯一亮色点缀，不要花花绿绿。
- **氛围**：夜晚宿舍书桌、一盏台灯、杯热饮，突出"凌晨跑通"的真实感，不要做成炫技的科技蓝紫赛博风。

## 封面文字（两行，居中偏下）
- 主标题（大字）：**我让电脑里的 AI 记住了我**
- 副标题（小字）：零基础 · 本地大模型 Agent 全过程复盘

## 不要出现
- 不要出现真实 GitHub 头像、真实二维码、真实链接。
- 不要堆术语（"Gemma""JSON"不放进封面，留给正文）。
- 不要用 AI 感过重的发光大脑、机器人头颅这类俗套素材。
