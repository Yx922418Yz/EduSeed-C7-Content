# 零基础用本地大模型做了一个会记忆的 Agent——C4D 全过程复盘

> 一个连 Git 都搞不明白的软件工程大一新生，想在自己笔记本上跑一个"能记住上次聊过啥"的 AI。这是我折腾一周、推翻三次、最后真的跑通的全过程。

## 先说结果，再说丢人

上周这个时候，我对着命令行里一行 `Memory saved to memory.json` 的输出，愣了三秒。

成了。

一个跑在我自己电脑上、不联网、不用花钱调 API 的小 Agent，真的记住了：我喜欢楷书、我在练兰亭序、我膝盖不好别推荐我蹲很久的练字帖。

你现在听到"本地大模型 Agent"可能觉得特别玄。我先说清楚我是谁：我，郑州西亚斯学院软件工程 2025 级，李亚轩，自评零基础。开学前我连"环境变量"是啥都要百度三遍。

但我愣是把它做出来了。这篇文章不吹不黑，把我踩的坑、走的弯路、以及三次推翻重来的过程，全写出来。

## 我为啥非要折腾"本地"，直接用网页版不香吗？

起因很简单。

我们 C4D 这个技能挑战，要求做一个"本地大模型 Agent"。一开始我是抗拒的：我直接用网页版 AI 不就行了，为什么要把几个 G 的模型下到自己电脑里？

真动手才想明白三件事：

- **不花钱。** 网页版用多了要充额度，本地跑一次是一次，随便造。
- **数据不出本机。** 我把自己练字的笔记、手写字的照片描述喂给它，这些东西我不想传到别人服务器上。
- **它是真的"我的"。** 这个 Agent 装在我电脑里，关机再开它还在，这种感觉很不一样。

一句话：**网页版是租房子，本地跑是自己装修。** 我想试试自己装修是什么感觉。

## 第一晚：下载模型，就给了我一个下马威

我选的模型是 **Gemma**（Google 出的那个开源小模型，对配置友好）。

我照着教程，敲下下载命令，然后……就开始等。

进度条像蜗牛。我这台笔记本，下了快俩小时。中间我甚至去食堂吃了顿饭，回来它还在爬。

等我兴冲冲地把模型加载起来，问它第一句话，它给我的回答是这样的：

> 对不起，我现在无法回答。

我：？？？我下你两个多小时，你就给我看这个？

后来才知道，**模型文件下了一半就断了，文件是坏的**。我以为进度条走完就完事，结果它悄悄在那装了个残血模型。

**教训一：大文件下载完，一定要校验一下大小或者重新加载测试。别信进度条。**

重下。又是俩小时。这回能对话了，但慢得像在挤牙膏，一个字一个字往外蹦。我看了眼任务管理器——

**内存占满了，硬盘在疯狂转。** 原来我让它加载了一个我这破笔记本根本扛不动的版本。

## 第二次翻车：它"记不住事"

模型能聊了，下一步是我真正想要的——**让它有记忆**。

我的设想很美好：我告诉它"我在练楷书"，下次我打开它，它得还记得我在练楷书。

结果呢？我每次关掉窗口再打开，它就像第一次见面一样：

> 您好！请问有什么可以帮您？

我：大哥，昨天才聊过。

这是我花最久才想明白的一个坑：**大模型本身是没有记忆的。** 它每说一句话，都是根据当前这一段文字现编的。你关掉窗口，它脑子里那点东西就全没了。

那"记忆 Agent"的记忆是哪来的？

答案特别朴素：**是外面用文件存的。**

说白了就是，每次对话前，程序先去读一个 `memory.json` 文件，把里面记的"主人喜欢楷书""膝盖不好"这些信息，**塞到这次提问的前面**；对话完了，再把新发生的事写回这个文件。

模型还是那个没记性的模型，是外面这层"读写文件"的壳，让它看起来像有记忆。

我当时整个人都精神了——原来"记忆"这么朴素，根本不是什么科幻黑科技。**它就是一个读写 JSON 的小动作。**

## 第三次换路：别硬刚，换个思路

真正让我卡住、最后逼我"换路"的，是"技能调用"这块。

我想让这个 Agent 不只是聊天，还能调用我写好的小工具（比如"帮我查一个字的毛笔笔顺"）。教程里写的是让模型自己判断"什么时候该调工具"。

我折腾了半天，模型就是不肯老老实实地调工具，要么自己瞎编一个答案，要么调错了参数。我跟它死磕了一晚上，越改越乱。

最后我做了一个特别重要的决定：**不硬刚了，换个对我这种水平友好的路子。**

我把流程改成"半自动"：

- 我不问它"你想干嘛"，
- 而是我先规定好：如果用户说的话里带某个关键词（比如"笔顺"），就直接去调对应的技能；
- 模型只负责在中间把话说得自然一点。

这么一改，立刻就通了。

**复盘这个坎我印象特别深：一开始我觉得"换路"是认怂，后来才明白——在自己能力不够的时候，选一条能跑通的笨办法，比硬撑一个高级架构重要一万倍。** 能跑，比优雅重要。

## 最后跑通的那一刻

凌晨一点多，我把 `memory.json` 读写逻辑加上，把技能调用改成半自动，重新跑了一遍：

我第一句："记住，我叫李亚轩，在练楷书。"
它回："好的，已经帮你记下了。"

我关掉窗口。重新打开。
我第二句："帮我查个练字建议。"

它这次没问我是谁，而是说：

> 亚轩你好～你之前说在练楷书、膝盖不太好，那我给你推荐几个坐着就能练、不用久蹲的描红帖吧……

我盯着屏幕，真的有点感动。

它其实"啥也没记住"，只是每次都老老实实去读那个文件。但就是这么一个土办法，**在我这台破笔记本上，实现了我一开始想要的效果。**

## 写给同样零基础的你

这一周我最大的收获，根本不是技术，是心态：

1. **别被名词吓住。** "本地大模型""Agent""记忆"听着高级，拆开看就是：下载个模型文件 + 读写一个 JSON + 几个关键词判断。
2. **能跑比优雅重要。** 我三次推翻，不是因为我多厉害，是因为前两版根本跑不通。先做丑的，再做好的。
3. **报错不是针对你。** 那个装残的模型、那个记不住事的破窗口，谁都遇到过。它只是在等你去查它而已。
4. **AI 是我的搭档，不是替身。** 整个过程每一步我都在跟 AI 反复对：报错了贴给它，卡住了描述给它。方向是我定的，活是它帮我一起干的。

一个月前我连环境变量都怕，现在我有了一个跑在自己电脑里、记得住我名字的小 Agent。

**技术这东西，真的不是聪明人的专利，是敢往下敲命令的人的。**
